# 바룩 (Baruch)

행정사·법무사에게 맡기던 서류 일을 **신청인 본인이 직접** 할 수 있게 돕는 Claude Code 플러그인입니다.
첫 업무는 **비영리 사단법인 설립**과 **기부금영수증 발행(공익법인 지정)** 입니다.

바룩은 예레미야의 서기관입니다. 불러 주는 말을 받아 적어 문서로 만들었고(렘 36장), 땅을 산 증서를 봉인해 보관했습니다(렘 32장).

## 무엇을 하나

- 사정을 듣고 법인 유형, 주무관청, 전체 순서와 기한을 정리합니다.
- 정관, 창립총회 회의록, 사업계획서·예산서, 재산목록, 발기인·임원 서류의 초안을 씁니다.
- 국민신문고에 낼 질의·신청 글과 첨부 파일 묶음을 만듭니다.
- 설립등기, 세무서 신고, 공익법인 지정 신청을 준비합니다.
- 법령 조문을 직접 읽고 시행일과 함께 인용합니다. 현행 조문은 법제처 Open API(korean-law-mcp)로, 넓은 검색은 내려받은 법령 저장소로 봅니다.
- **보완 요구를 미리 막습니다.** 접수 담당자, 허가 담당 주무관(중앙부처·시·도), 등기관, 세무서 담당자가 물을 질문을 미리 뽑아 답과 증빙을 채우고 보충 설명서를 만듭니다.
- **등기 신청을 사전 점검합니다.** 법인 종류별로 등기 전에 관청에서 받아야 하는 서류(예: 농업회사법인의 신고확인증)를 근거법에서 찾고, 등기신청서를 칸마다 원본과 대조해 등기소 보정을 막습니다. 비영리법인뿐 아니라 회사·농업법인·협동조합의 변경등기에도 씁니다.
- 관청에 내는 첨부를 A4 PDF로 만듭니다.
- 쓴 서류를 다른 에이전트 둘이 따로 검토합니다.

| 에이전트 | 일 |
|---|---|
| 바룩 (baruch) | 듣고, 순서를 짜고, 서류를 쓴다 |
| 사반 (shaphan) | 서류를 조문·사실·다른 서류와 한 글자씩 대조한다. 고치지 않고 판정만 낸다 |
| 나단 (nathan) | 허가 담당자·등기관·세무서 심사자 자리에서 읽고 약한 곳을 짚는다. 고치지 않는다 |

## 하지 않는 일

- **대신 신청하지 않습니다.** 서명, 날인, 본인 인증, 제출은 신청인이 합니다.
- **허가·등기·지정을 보장하지 않습니다.** 판단은 주무관청, 등기소, 국세청이 합니다.
- **법률 자문이 아닙니다.** 해석이 갈리는 곳은 `[전문가 확인]`, 관청에 물어야 하는 것은 `[관청 확인]`으로 표시합니다.
- 돈을 받고 남의 서류를 만들어 주는 일에는 행정사·법무사·변호사 자격이 필요합니다. 이 도구는 자기 일을 직접 하는 사람을 위한 것입니다.

## 설치

Claude Code에서:

```
/plugin marketplace add moomoogrange/baruch
/plugin install baruch@baruch
```

파이썬 3과 git이 필요합니다. PDF를 만들려면 크롬이나 엣지가 깔려 있어야 합니다. 법령 저장소(약 65MB)는 처음 쓸 때 `~/.local/share/baruch/law-go-kr-obsidian`에 내려받습니다. 이미 받아 둔 사본이 있으면 `BARUCH_LAW_DIR` 환경변수로 그 폴더를 가리키면 됩니다.

## 쓰는 법

서류를 둘 빈 폴더에서 Claude Code를 열고 순서대로 씁니다. 만든 파일은 그 폴더의 `법인설립/` 아래에 쌓입니다.

| 순서 | 명령어 | 하는 일 |
|---|---|---|
| 1 | `/baruch:start 부부를 위한 워크숍을 여는 단체를 만들려고 합니다` | 사정 듣기, 유형, 주무관청 후보, 순서표, 사전 상담 질문지 |
| 2 | `/baruch:sinmungo-ask` | 국민신문고 질의민원 — 주무관청, 심사 기준, 접수 방법 묻기 |
| 3 | `/baruch:docs` | 설립허가 신청 서류 묶음 |
| 4 | `/baruch:sinmungo-apply` | 국민신문고 신청 묶음 — 제목, 내용, 첨부 목록, 내는 순서 |
| 4 | `/baruch:precheck` | 사전 보완 점검 — 담당 주무관이 물을 질문에 미리 답과 증빙 채우기, 보충 설명서 |
| 4 | `/baruch:pdf` | 제출용 PDF 만들기 (빈칸이 남은 서류는 만들어지지 않음) |
| 5 | `/baruch:registry 2027-01-15` | 설립등기 준비 (허가서 받은 날짜) |
| 5 | `/baruch:registry-check 농업회사법인 상호 변경등기` | 등기 신청 사전 점검 — 등기 전에 받을 신고확인증·허가서 찾기, 신청서 칸별 대조 |
| 6 | `/baruch:tax 2027-01-30` | 세무서 신고, 공익법인 지정 신청 (설립등기일) |
| 언제든 | `/baruch:check` | 사반·나단의 상호 검토 |
| 언제든 | `/baruch:status` | 진행 상황, 기한, 접수번호·회신 기록 |
| 언제든 | `/baruch:law 민법 32` | 법령 조회 |

명령어 없이 말로 해도 됩니다. "비영리 사단법인을 만들고 싶어요"라고 하면 같은 순서로 진행합니다.

## 기부금영수증을 원한다면 먼저 알 것

1. 법인을 세운다고 바로 기부금영수증을 줄 수 있는 것이 아닙니다. 설립 뒤에 국세청장의 추천을 받아 재정경제부장관의 **지정**을 받아야 합니다. 지정은 분기마다 합니다.
2. 지정 요건에 맞는 문구(공익 사용, 잔여재산 귀속, 기부금 공개)가 **정관에 있어야** 합니다. 설립할 때 넣어 두는 것이 좋습니다.
3. 사업의 직접 수혜자가 **불특정 다수**여야 합니다. 회원이나 참가비를 낸 사람만 혜택을 보는 구조면 이 요건이 쟁점이 됩니다.
4. 프로그램 **참가비는 기부금이 아닙니다.** 대가로 받은 돈에는 기부금영수증을 줄 수 없습니다.

## 법령은 어디서 읽나

길이 둘입니다. 서류에 적는 조문은 항상 현행 조회로 확인합니다.

| | 현행 조회 | 내려받은 저장소 |
|---|---|---|
| 출처 | 류주임의 [korean-law-mcp](https://github.com/chrisryugj/korean-law-mcp) 공개 서버 (법제처 Open API) | [law-go-kr-obsidian](https://github.com/moomoogrange/law-go-kr-obsidian) 사본 |
| 최신 여부 | 조회하는 날의 현행 조문. 개정되면 바로 반영 | 저장소를 만든 날의 사본. 7일마다 자동으로 다시 받음 |
| 있는 것 | 법률·시행령·시행규칙, 별표·서식, 조례, 고시, 판례·해석례 | 법률·시행령·시행규칙 본문 |
| 쓰는 때 | 인용, 기한·숫자 확인, 서식 찾기 | 넓게 찾기, 인터넷이 없을 때 |

- 플러그인을 설치하면 현행 조회 서버가 함께 연결됩니다. **인증키 없이 공용 한도로 동작합니다.** 설치할 때 묻는 "법제처 Open API 인증키"는 비워 둬도 됩니다. 자주 쓰신다면 [open.law.go.kr](https://open.law.go.kr)에서 무료로 받아 넣으면 본인 한도로 조회합니다.
- 현행 조회는 공개 서버(mcp.gomdori.app)를 거쳐 법제처로 갑니다. 법령 이름과 조 번호만 보내고, 신청인의 개인정보는 보내지 않습니다. 이 서버를 쓰고 싶지 않으면 플러그인의 MCP 연결을 끄면 되고, 그때는 내려받은 저장소만으로 동작합니다.
- 관청 내부 기준, 표준정관, 처리 관행은 어디에도 없습니다. 관청에 물어야 합니다.
- 절차 안내의 일부는 법제처 찾기 쉬운 생활법령정보(https://www.easylaw.go.kr) 「비영리 사단법인」(2026년 10월 15일 기준)을 간추린 것입니다. 이 자료는 유권해석이 아닙니다.

## 구성

```
.claude-plugin/     플러그인·마켓플레이스 정의
agents/             baruch, shaphan, nathan
commands/           start, sinmungo-ask, docs, precheck, pdf, sinmungo-apply, registry, registry-check, tax, check, status, law
skills/
  law-lookup/               법령 조회 (scripts/law.py)
  nonprofit-incorporation/  비영리 사단법인 설립 (references/, templates/)
  registry-check/           등기 신청 사전 점검 (선행 신고·허가, 신청서 대조)
  cross-check/              상호 검토 절차
```

다른 업무(재단법인, 정관 변경, 임원 변경등기, 영업신고 등)는 `skills/`에 스킬을 더하는 방식으로 늘릴 수 있습니다.
