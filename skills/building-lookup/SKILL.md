# 건축물 조회

건물이 걸린 신청은 **대장에 적힌 것과 신청서에 적는 것이 같아야** 받는다. 용도, 면적, 구조, 사용승인일을 신청인의 기억으로 적으면 보완 요구가 온다. 서류를 쓰기 전에 대장 기록을 먼저 읽는다.

조회는 류주임이 만든 [archhub-mcp](https://github.com/chrisryugj/archhub-mcp) 공개 서버를 거쳐 국토교통부 건축HUB(공공데이터포털)로 간다. 인증키는 필요 없다.

## 조회하는 법

세션에 `archhub` MCP 도구(`find_region`, `building_profile`, `parcel_history` 등)가 붙어 있으면 그것을 쓴다. 이 플러그인을 설치하면 함께 연결된다. 도구는 주소를 바로 받지 않는다. **먼저 `find_region`으로 시군구 코드와 법정동 코드를 얻고**, 그 코드와 번지를 다른 도구에 넘긴다.

도구가 없거나 하위 에이전트라서 못 쓰면 이 스킬 폴더의 `scripts/arch.py`로 같은 서버를 부른다. 스크립트는 주소를 그대로 받아 코드를 스스로 찾는다. 파이썬 3만 있으면 된다.

```bash
arch.py region  광진구 자양동                 # 법정동 코드 찾기
arch.py profile 광진구 자양동 2-2             # 종합카드 — 용도지역, 주용도, 구조, 면적, 건폐율·용적률, 사용승인일, 정화조
arch.py history 광진구 자양동 2-2             # 필지 연혁 — 허가 → 착공 → 사용승인, 철거, 가설건축물
arch.py floors  광진구 자양동 2-2             # 층별 용도와 면적
arch.py temp    광진구 자양동 2-2             # 가설건축물과 존치기간 만료일 (번지를 빼면 동 전체)
arch.py raw ledger 표제부 광진구 자양동 2-2    # 대장 원본 행
arch.py tools                                # 도구 목록
arch.py call 도구이름 '{"인자":"값"}'          # 도구를 직접 부르기
```

- 주소는 **시·군·구, 법정동(읍·면·리), 번지** 순으로 띄어 쓴다. 행정동(자양1동)이 아니라 법정동(자양동)이다. 도로명주소로는 찾지 못한다. 지번을 모르면 신청인에게 묻거나 토지이음에서 찾게 한다.
- 같은 이름의 동이 여럿이면 스크립트가 목록을 보여 주고 멈춘다. 시·군·구를 붙여 하나로 좁힌다.
- 동 전체를 받는 조회(번지 없는 `temp`, `raw`)는 느리고 공용 서버의 한도를 쓴다. 필지 하나를 볼 때는 반드시 번지를 붙인다.

## 어느 조회를 쓰나

| 알고 싶은 것 | 조회 | 쓰이는 업무 |
|---|---|---|
| 이 건물의 대장상 용도·구조·면적·사용승인일, 그 땅의 용도지역 | `profile` (`building_profile`) | 영업신고 전 건물 용도 확인, 용도변경, 건축신고·허가, 신청서의 건물 표시 |
| 층마다 어떤 용도로 몇 제곱미터인지 | `floors` (`building_floors`) | 용도변경(바꾸려는 층의 현재 용도), 영업장 면적 |
| 정화조 형식과 용량 | `profile`의 정화조 줄, 자세히는 `raw ledger 오수정화시설` | 용도변경에서 오수 발생량 검토 |
| 이 필지에서 받은 허가·신고와 사용승인 여부, 철거 기록 | `history` (`parcel_history`) | 처분 대응, 원상회복 요구, 무허가 다툼, 매수·대부 전 확인 |
| 가설건축물이 신고돼 있는지, 존치기간이 언제 끝나는지 | `temp` (`temp_buildings`) | 가설건축물 축조신고, 존치기간 연장신고, 기한 장부 |
| 한 대장에 딸린 다른 지번, 전유·공용 면적 등 원본 행 | `raw ledger 부속지번` · `raw ledger 전유공용면적` 등 | 여러 필지에 걸친 건물, 집합건물 |

`raw`의 대장 종류는 `ledger`(건축물대장) · `permit`(건축인허가) · `housing`(주택인허가)이고, 세부 유형 이름은 `arch.py tools`나 도구 설명에 있다. 서버에는 동 단위 통계, 노후 건축물, 내진, 공시가격 도구도 있다. 신청 서류에는 거의 쓰지 않는다. 필요하면 `call`로 부른다.

## 반드시 지킬 것

1. **조회 결과는 대조용이다. 붙이는 서류가 아니다.** 관청에 내는 것은 정부24나 세움터에서 뗀 **건축물대장 등본**이다. 조회 결과로 초안을 쓰고, 신청인이 등본을 떼어 오면 다시 맞춘다. `98-신청인이-할-일.md`에 "건축물대장 떼기"를 적는다.
2. **읽은 것만 적고, 읽은 날을 적는다.** 서류와 `00-기초사실.md`에 옮길 때 "건축HUB 조회(조회일 ○○○○-○○-○○)"라고 출처를 붙인다. 대장 기록은 실제 처리보다 늦게 올라올 수 있다.
3. **없다고 나온 것은 없다고 적는다.** `[NOT_FOUND]`가 나오거나 서버에 닿지 못하면 지어내지 않는다. `[확인 필요: 건축물대장]`으로 남긴다. 대장이 없는 건물(무허가, 미등재)과 건물이 없는 땅은 조회되지 않는다. **조회되지 않았다는 것이 건물이 없다는 뜻은 아니다.**
4. **여기서 볼 수 없는 것을 안다.**
   - **위반건축물 표시**는 나오지 않는다. 나오지 않았다고 위반이 없는 것이 아니다. 등본에서 본다.
   - **소유자**는 나오지 않는다. 소유자는 등본과 등기사항증명서에서 본다.
   - **토지 정보**(지목, 면적, 공시지가)는 없다. 토지대장과 토지이용계획확인서에서 본다. 용도지역은 건물이 있는 필지만 나오므로, 서류에 적는 용도지역은 토지이용계획확인서로 확정한다.
   - **"산" 번지**를 따로 가리지 못한다. 결과의 대지위치가 찾던 필지인지 확인한다.
5. **가설건축물의 "만료 경과"는 위반이라는 뜻이 아니다.** 연장신고가 대장에 늦게 올라오거나 만료일이 비어 있는 일이 있다. 신고필증과 관청 답으로 확정한다 `[관청 확인]`. 만료일은 `기한.md`에 적는다.
6. **주소만 보낸다.** 조회어에는 시·군·구, 동, 번지만 넣는다. 신청인의 이름, 상호, 사연을 넣지 않는다. 주소는 공개 서버(mcp.gomdori.app)를 거쳐 공공데이터포털로 간다. 신청인이 주소를 밖으로 보내기를 꺼리면 조회하지 않고 등본으로만 일한다.
7. **결과에 섞인 남의 이름을 옮기지 않는다.** 인허가 기록의 건물 이름 칸에 사람 이름이 들어 있는 일이 있다. 신청과 상관없는 이름은 서류에 적지 않는다.
8. **대장과 실제가 다르면 그 차이부터 다룬다.** 대장의 용도·면적이 신청인의 말과 다르면 어느 쪽이 맞는지 묻고, 대장을 고치는 일(용도변경, 표시 변경, 증축 신고)이 먼저인지 `admin-affairs` 스킬의 토지·건축·농지 카드에서 본다. 허가 없이 바꿔 쓴 것으로 보이면 숨기지 않고 `[전문가 확인]`을 붙인다.
