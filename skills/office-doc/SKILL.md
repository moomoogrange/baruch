# 직접 고칠 수 있는 파일로 주기

바룩이 쓴 초안은 작업용 `.md`다. 신청인이 그 파일을 직접 고치기는 어렵다. 이 스킬은 초안을 워드 파일로 만들어 신청인이 **열어서 직접 타이핑**하게 하고, 고친 내용을 다시 읽어 온다.

이음오피스([pblsketch/ieumoffice](https://github.com/pblsketch/ieumoffice), Apache-2.0)를 쓴다. 문서를 만들고 읽고 바꾸는 일은 모두 신청인의 컴퓨터 안에서 되고 밖으로 보내지 않는다. 이 스킬은 이음오피스의 검색·그림·웹 읽기 기능은 쓰지 않는다.

## 쓸 수 있는지 먼저 본다

1. 연결 도구가 있는가: 도구 목록에 `ieumoffice`의 `create_docx`, `docs_read`, `convert`가 보이면 그것을 쓴다.
2. 없으면 명령어가 있는가: `ieumoffice --version`.
3. 둘 다 없으면 이 스킬을 쓰지 않는다. 신청인에게 한 줄로 알린다: "이음오피스를 깔면 초안을 워드 파일로 열어 직접 고칠 수 있습니다. https://ieumoffice.com" 그리고 지금까지처럼 초안 PDF(`/baruch:pdf 초안`)를 주고 고칠 곳을 말로 받는다. 설치를 대신 하지 않는다.

## 원칙

- **원본은 `.md`다.** 워드 파일은 신청인이 타이핑하는 자리다. 제출용 PDF, 빈칸 검사, 상호 검토는 모두 `.md`를 본다.
- **워드 파일을 `.md`로 통째로 덮어쓰지 않는다.** 워드를 거치면 가로줄(`---`)과 일부 표시가 빠져서, 제출용에서 빼야 할 "쓰는 사람 안내"가 본문에 섞일 수 있다. 고친 내용만 골라 `.md`에 옮긴다.
- **신청인이 적은 것은 그대로 옮긴다.** 맞춤법이 틀려 보여도 이름·주소·금액·날짜는 고치지 않고, 이상하면 묻는다.
- **빈칸을 지어내 채우지 않는다.** 워드 파일에도 `{{…}}`와 `[확인 필요: …]`을 그대로 남긴다. 신청인이 그 자리에 적는다.

## 순서

### 1. 워드 파일을 만든다

```bash
ieumoffice create --type docx --from "업무/<업무>/12-정관.md" --out "업무/<업무>/고치기/12-정관.docx"
```

- `고치기/` 폴더에 원본과 같은 이름으로 만든다. 이미 있는 파일은 신청인이 고치던 것일 수 있으니 `--force`를 쓰기 전에 묻는다.
- 맨 위의 "초안 — 신청인 검토 전" 줄과 끝의 쓰는 사람 안내는 그대로 들어간다. 신청인이 읽고 쓰라고 둔 것이다.
- 만든 뒤 `ieumoffice render <파일> --out <폴더>`로 쪽 그림을 한 번 보고 표가 깨지지 않았는지 확인한다.

### 2. 신청인에게 연다

```bash
ieumoffice open "업무/<업무>/고치기/12-정관.docx"
```

- 신청인이 열어 달라고 했을 때만 연다. 아니면 파일 위치만 알려 준다.
- 어디를 채워야 하는지 알려 준다: "`{{ }}`와 `[확인 필요]`로 표시된 곳에 직접 적으시면 됩니다. 조문 번호와 인용한 법령 문구는 고치지 마시고, 바꾸고 싶으면 말씀해 주십시오."
- 다 고치면 **저장하고 알려 달라**고 한다.

### 3. 고친 내용을 읽어 온다

```bash
ieumoffice convert "업무/<업무>/고치기/12-정관.docx" --to md --out "<임시 폴더>/12-정관.md"
```

- 읽어 온 글과 원본 `.md`를 나란히 놓고 **달라진 곳만** 찾는다. 표의 칸 너비, `\~` 같은 표기, 빠진 가로줄과 굵은 글씨는 달라진 것이 아니다.
- 달라진 곳을 표로 신청인에게 보여 준다: 어디가, 무엇에서 무엇으로.
- 확인받은 뒤 원본 `.md`의 그 자리만 고친다.
- 신청인이 조문 인용이나 법이 정한 문구를 바꿨으면 옮기기 전에 현행 조문을 다시 읽고(`law-lookup`), 달라지면 그 사실을 알린다.

### 4. 이어서 한다

- 이름·주소·날짜·금액이 바뀌었으면 같은 값이 적힌 다른 서류도 찾아 맞춘다(`00-기초사실.md`부터).
- 상호 검토(`cross-check`)를 이미 받은 서류를 고쳤으면 다시 받는다.
- 제출용은 지금까지처럼 `.md`에서 만든다(`/baruch:pdf`). 빈칸이 남으면 만들어지지 않는다.

## 관청 서식(별지 서식)

관청이 정한 서식은 **그 서식 원본에** 적어야 한다. 바룩이 워드로 비슷하게 그려서 내게 하지 않는다. 법령에 딸린 서식 원본은 국가법령정보센터(law.go.kr)에서 바로 받는다. 인증키는 필요 없고, 보내는 것은 법령 이름과 서식 번호뿐이다.

```bash
python3 scripts/forms.py list "식품위생법 시행규칙" 신고서        # 서식 이름과 번호
python3 scripts/forms.py get  "식품위생법 시행규칙" 37 -o 업무/<업무>/서식   # 한글 파일
python3 scripts/forms.py get  "식품위생법 시행규칙" 41의2 --pdf -o …        # PDF
```

1. **어느 서식인지 정한다.** 업무 카드에 번호가 있으면 `references/서식-목록.md`에서 법령 이름과 번호를 본다(카드에 적힌 72건을 법제처 목록과 맞춰 둔 것). 없으면 `forms.py list`로 찾아 신청인에게 확인받는다. 이름이 비슷한 서식이 여럿이면 조문(`law-lookup`)에서 "별지 제○호서식" 번호를 읽어 정한다.
2. **받는다.** `업무/<업무>/서식/`에 받는다. 스크립트가 알려 주는 법령 시행일과 서식 시행일을 서류 목록에 적는다. 서식은 법령이 바뀌면 함께 바뀌니 **예전에 받아 둔 파일을 다시 쓰지 않고 낼 때 새로 받는다.**
3. **칸을 읽고 적을 내용을 정리한다.** 이음오피스가 있으면 `ieumoffice hwp read <파일>`로, 없으면 `law.py live annex "법령 이름" 번호`로 칸을 읽는다. 칸마다 적을 내용을 `<서식 이름>-적을-내용.md`로 정리한다. 서식 뒤쪽의 구비서류, 수수료, 처리기간, 유의사항도 함께 옮겨 서류 목록과 맞춘다.
4. **신청인이 적는다.** 이음오피스가 있으면 `ieumoffice open`으로 서식을 열어 주고, 신청인이 정리된 내용을 보고 직접 타이핑한다. 한글(한컴오피스)에서 열어도 된다. 바룩이 서식 파일에 직접 써 넣는 것(`ieumoffice hwp apply`)은 신청인이 해 달라고 할 때만 한다. 주민등록번호와 서명·날인 칸은 비워 둔다.
   - 쓰기 전에 `read_table`로 칸 번호를 읽는다. 관청 서식은 칸 이름과 적을 자리가 한 칸에 같이 있는 경우가 많다. 그때는 칸 이름 아래에 줄을 더한다(`insert_paragraphs`의 `anchor`에 칸 이름). 빈칸은 `fill_cells`, `[  ]` 표시는 `replace_text`로 `[√]`.
   - 원본은 건드리지 않고 사본에 쓴다. 덮어쓰면 이음오피스가 `.bak`을 남긴다.
   - 쓴 뒤 `read_table`로 다시 읽어 칸 수와 병합이 원본과 같은지, 적은 값만 달라졌는지 맞춘다.
   - **한글 파일은 쪽 그림으로 뽑아 볼 수 없다**(`ieumoffice render`와 PDF 변환이 한글 파일을 받지 않는다). 줄을 더하면 그 줄만큼 칸이 길어져 한 쪽짜리 서식이 다음 쪽으로 넘어갈 수 있다. `ieumoffice open`으로 열어 신청인이 쪽이 넘어가지 않았는지 눈으로 보게 하고, 넘어갔으면 글을 줄이거나 "별지 참조"로 적고 별지를 붙인다. 낼 PDF는 신청인이 이음오피스나 한글에서 인쇄해 만든다.
5. **다 적은 서식을 대조한다.** 신청인이 저장했다고 하면 `ieumoffice hwp read`로 다시 읽어, 적힌 이름·주소·날짜·면적이 `00-기초사실.md`와 다른 서류와 같은지 맞춘다. 이어서 상호 검토(`cross-check`).

**여기서 받을 수 없는 것**: 법원·등기소의 양식(대한민국 법원 전자민원센터, 인터넷등기소에서 받는다), 고시·훈령·예규에 딸린 서식, 관청이 따로 만든 양식, 조례·규칙의 서식. 어디서 받는지 알려 주고 받은 파일로 3번부터 한다. 주무관청이 정해지지 않은 일(비영리법인 설립허가 등)은 주무관청이 정해진 뒤 **그 부처 규칙의** 서식을 받는다.

## 대화창(Claude·ChatGPT)에서

이음오피스 연결 도구가 대화에 함께 붙어 있을 때만 쓴다. 초안을 `create_docx`로 만들어 파일로 주고, 신청인이 고쳐서 다시 올리면 `docs_read`로 읽어 달라진 곳을 표로 확인받는다. 도구가 없으면 서류를 대화 안에 써 주고, 한글이나 워드에 붙여 넣어 고치는 법을 알려 준다.

관청 서식은 대화창에서 `forms.py`를 쓸 수 없다. `references/서식-목록.md`의 "누리집" 주소를 신청인에게 알려 주고(그 쪽에서 한글·PDF 파일을 받는다), 목록에 없는 서식은 `law_annex`로 번호와 이름을 찾아 `https://www.law.go.kr/법령별표서식/(법령 이름,서식번호)` 꼴의 주소를 알려 준다. 칸마다 적을 내용은 `law_annex`로 서식을 읽어 정리해 준다.
