# 도면 그리기

관청은 신청서에 **배치도**(땅 위에 건물이 어디에 놓이는지)와 **평면도**(건물 하나를 위에서 본 모양과 크기)를 붙이라고 한다. 가설건축물 축조신고는 「건축법 시행규칙」 제13조제1항제1호가 "가설건축물의 배치도 및 평면도"를 붙이라고 정한다(확인일 2026-11-16). 간단한 건물은 신청인이 직접 그려도 받는 곳이 많다 `[관청 확인]`.

이 스킬은 신청인이 불러 준 치수를 받아 적어 도면으로 옮긴다. **측량을 대신하지 않는다.**

## 그리기 전에 받을 것

자리와 치수를 짐작해서 그리면 틀린다. 아래를 신청인에게서 받은 뒤에 그린다. 모르는 것이 있으면 그리지 않고 묻는다.

| 받을 것 | 어디서 |
|---|---|
| 새로 놓을 건물의 가로, 세로, 구조, 용도 | 신청인. 컨테이너는 실물이나 견적서의 규격 |
| 기존 건물의 가로, 세로 | 건축물대장의 면적만으로는 모양을 알 수 없다. 신청인이 재거나 기존 도면에서 읽는다. 대장 기록은 `building-lookup` 스킬로 맞춘다 |
| **새 건물이 놓일 자리** — 기존 건물이나 경계에서 어느 쪽으로 몇 미터 | 신청인이 현장에서 잰다. 차가 드나드는 길, 문 앞, 비탈처럼 놓을 수 없는 곳도 함께 묻는다 |
| **방위** — 도면에서 북쪽이 어느 쪽인지 | 지적도, 지도 앱, 나침반 |
| 대지경계선의 모양과 길이, 대지면적 | 브이월드 인증키가 있으면 `parcel.py`로 지번의 경계를 받는다(아래 "필지 경계 받기"). 없으면 지적도 등본에서 읽는다. 면적은 토지대장. 경계를 모르면 그리지 않고 주기에 적는다 |
| 대지에 닿은 도로나 진입로의 위치와 너비 | 지적도, 현장 |
| 문과 창의 위치와 폭 (평면도) | 신청인, 실물 |

받은 값은 `00-기초사실.md`에 출처와 함께 적는다. 신청인에게 손으로 그린 약도나 지적도 사진을 받으면 가장 빠르다.

## 그리는 법

이 스킬 폴더의 `scripts/draw.py`를 쓴다. 파이썬 3만 있으면 SVG가 나오고, 크롬이나 엣지가 있으면 PDF와 미리보기 PNG도 나온다.

```bash
draw.py example 배치도 > 업무/<업무 이름>/첨부/배치도.json    # 보기 파일로 시작
draw.py example 평면도 > 업무/<업무 이름>/첨부/평면도.json
draw.py check 배치도.json                                  # 적힌 값 점검
draw.py make 배치도.json                                   # 같은 폴더에 .svg .pdf .png
```

1. 보기 파일을 만들고 신청인의 값으로 바꿔 적는다.
2. `make`로 그린다. 고쳐야 할 것이 있으면 그리지 않고 알려 준다. `[살필 것]`으로 나오는 것은 그려지지만 하나씩 확인한다.
3. **PNG를 열어 눈으로 본다.** 건물이 말한 자리에 있는지, 방위표가 맞는지, 글자와 치수가 겹치지 않는지. 겹치면 `가로치수`·`세로치수`의 자리를 바꾸거나 치수의 `띄움`을 준다.
4. 신청인에게 PNG를 보여 주고 **"이 자리가 맞습니까"**를 확인받는다. 확인받기 전에는 내지 않는다.
5. 낼 때는 PDF를 붙인다. A4 가로 한 장이다.

## 필지 경계 받기

신청인이 대지경계선의 좌표를 아는 일은 드물다. 브이월드(국토교통부 공간정보 오픈플랫폼)의 연속지적도에서 지번으로 경계를 받아 도면 파일에 넣는다.

```bash
parcel.py show 광진구 자양동 2-2                 # 지번, 지목, 지도에서 잰 넓이, 가운데 좌표
parcel.py show 평창군 대관령면 횡계리 산 1-1      # 산 번지
parcel.py into 배치도.json 광진구 자양동 2-2      # 도면 파일에 대지경계·대지면적(대장)·주소·방위(위쪽이 북)·원점을 채운다
parcel.py into 배치도.json 광진구 자양동 2-2 --buildings   # 그 필지의 기존 건물 윤곽과 건축물대장 건축면적도 넣는다
```

- **신청인 본인의 브이월드 인증키가 있어야 한다.** [vworld.kr](https://www.vworld.kr)에 가입해 오픈API 인증키를 발급받는다(무료, 개발키 6개월, 연장 가능). 서비스유형은 "기타", 활용API는 2D데이터·WMTS/TMS·국가중점 API를 고른다(전부 골라도 된다). 키는 환경변수 `VWORLD_KEY`에 넣거나 `~/.config/baruch/vworld_key` 파일에 한 줄로 적는다. 약관상 인증키는 발급받은 회원만 쓸 수 있으므로 남의 키를 빌려 쓰게 하지 않는다. 키를 대화창에 적게 하지 않는다.
- 키가 없으면 이 기능만 못 쓴다. 지적도 등본에서 경계를 읽어 직접 적으면 된다.
- `into`를 쓰면 좌표가 정해진다. **필지를 둘러싼 네모의 남서쪽 모서리가 `[0, 0]`, x는 동쪽, y는 북쪽**이다. 건물의 위치는 이 좌표로 적는다. 신청인이 "서쪽 경계에서 몇 미터, 기존 건물 북쪽 벽에서 몇 미터"처럼 불러 준 값을 이 좌표로 옮긴다.
- 필지가 건물에 비해 아주 크면(임야, 목장, 농지) `범위`에 `[왼쪽 x, 아래 y, 오른쪽 x, 위 y]`를 적어 건물 둘레만 크게 그린다. 도면에 "대지의 일부만 그린 도면"이라고 찍힌다.
- `show`가 알려 주는 가운데 좌표를 `slope.py`에 넣으면 그 필지의 경사 참고도가 된다.
- **연속지적도는 참고용이다.** 지적도 등본이나 측량 성과가 아니고 실제 경계와 어긋날 수 있다. 도면 주기에 출처와 조회일이 찍힌다. 경계에 가까이 짓는 일, 경계가 다투어지는 땅은 경계복원측량을 권한다 `[전문가 확인]`.
- `--buildings`로 넣은 건물 윤곽은 지도에 올라 있는 것이다. 이미 철거된 건물이 남아 있거나 새 건물이 빠져 있을 수 있다. 신청인에게 지금 있는 건물이 맞는지 묻고, 아닌 것은 지운다. 건물 이름 칸에 사람 이름이 섞여 오는 일이 있어 이름은 "기존 건물 1"처럼 붙인다.

## 대장 면적과 맞추기

신청서에 적는 면적은 **대장에 적힌 면적**이다. 지도에서 잰 넓이가 아니다. 도면도 대장과 같아야 한다.

- `parcel.py`는 토지대장(산 번지는 임야대장)의 지목과 면적을 받아 지도 경계로 잰 넓이와 나란히 보여 주고, `into`는 대장 면적을 `대지면적`에 넣는다. 도면에는 대장 면적과 출처가 찍히고 그 아래에 경계선으로 잰 넓이가 작게 찍힌다.
- 건물에 `대장면적`(건축물대장의 건축면적)을 적으면 개요표에는 대장 면적이 찍히고, 그린 넓이는 옆에 작게 찍힌다. `--buildings`가 채워 준다. 손으로 그린 기존 건물에도 건축물대장을 보고 `대장면적`을 적는다.
- `draw.py`는 둘이 2%보다 더 다르면 `[살필 것]`으로 알린다. **숫자를 맞추려고 경계나 치수를 늘이거나 줄이지 않는다.** 다른 까닭을 찾는다.
  - 대지: 분할·합병이 지도에 늦게 반영됐다, 한 대지가 여러 필지다(건축물대장의 대지면적은 부속지번을 합친 값이다), 지번이나 산 여부가 틀렸다.
  - 건물: 증축했는데 대장에 없다, 일부를 철거했다, 지도 윤곽이 처마 끝을 따라 그려졌다, 치수를 잘못 쟀다.
- 까닭이 "실제가 대장과 다르다"이면 그것이 먼저 풀 일이다. 대장을 고치는 신청(표시 변경, 증축 신고, 지적 정정)을 `admin-affairs` 스킬의 토지·건축·농지 카드에서 찾고 `[전문가 확인]`을 붙인다.
- 조회로 받은 대장 면적은 대조용이다. 낼 때는 신청인이 뗀 토지(임야)대장·건축물대장 등본과 다시 맞춘다.

## 바탕에 지도 깔기

도면 파일의 `바탕`에 `"항공사진"`, `"지도"`, `"지적도"` 가운데 하나나 여럿을 적으면 건물과 경계선 밑에 깔린다. 관청이 "지적도 위에 표시한 배치도"를 원할 때, 그리고 건물 자리가 맞는지 신청인과 눈으로 확인할 때 쓴다.

```json
"바탕": ["항공사진", "지적도"]
```

- `parcel.py into`로 `원점`이 들어간 도면 파일에서만 된다. 브이월드 인증키가 필요하고 `draw.py make` 때 인터넷으로 받는다.
- `지적도`는 둘레 필지의 경계선과 지번을 선으로 그린다. 흑백으로 인쇄해도 읽힌다. `항공사진`은 흑백 인쇄에서 어두워질 수 있으니 낼 때는 `지적도`만 깐 것을 함께 만들어 둔다.
- 항공사진은 가장 큰 확대 단계가 정해져 있어 1/200보다 크게 그리면 흐리다. 찍은 때가 몇 해 전일 수 있어 새 건물이 없거나 없어진 건물이 보일 수 있다.
- 사진과 지적선은 몇 미터쯤 어긋나 보일 수 있다. 사진을 보고 경계를 판단하지 않는다.
- 도면 주기에 "바탕: 브이월드 … (국토교통부, 조회일)"이 찍힌다. 브이월드 약관이 출처 표시를 요구하므로 지우지 않는다.
- 조회할 때 지번(PNU)이 신청인의 인증키와 함께 브이월드로 간다. 이름이나 사연은 보내지 않는다.

## 적는 칸

길이와 좌표는 모두 **미터**다. x는 도면의 오른쪽으로, y는 도면의 위쪽으로 커진다. 원점은 편한 곳(보통 대지의 왼쪽 아래 모서리나 기존 건물의 모서리)에 둔다. 도면의 치수 글자는 mm로 찍힌다.

| 칸 | 뜻 |
|---|---|
| `종류` | `배치도` · `평면도` · `현황도` (현황도는 지금 있는 그대로를 그린 배치도) |
| `제목`, `주소`, `용도` | 도면 이름, 대지 주소, 어디에 내는 도면인지 |
| `작성일`, `작성자` | 도면 아래에 찍힌다. 작성자는 비워도 된다 |
| `방위` | 도면에서 북쪽이 가리키는 쪽. `위` · `오른쪽` · `아래` · `왼쪽`, 또는 위에서 시계 방향으로 잰 각도. **필수** |
| `위치근거` | 자리와 거리를 어디서 얻었는지. 배치도와 현황도는 **필수**이고 도면의 주기에 찍힌다 |
| `축척` | 비우면 종이에 맞는 표준 축척을 고른다. 정하려면 숫자(300이면 1/300) |
| `대지경계` | 경계선의 꼭짓점 `[x, y]` 목록. `parcel.py into`가 채워 준다. `대지면적`은 제곱미터 |
| `범위` | 큰 대지의 일부만 그릴 때 `[왼쪽 x, 아래 y, 오른쪽 x, 위 y]` |
| `바탕` | 밑에 깔 지도. `항공사진` · `지도` · `지적도` 가운데 하나 또는 목록 |
| `대지면적출처`, `원점` | `parcel.py into`가 넣는다. 손대지 않는다 |
| `건물` | 아래 표 |
| `표시` | `도로`·`구역`(위치·가로·세로 또는 꼭짓점, `이름`), `글자`(`위치`, `글`), `화살표`(`시작`, `끝`, `글`) |
| `치수` | 두 점 사이 거리. `시작`, `끝`, 필요하면 `띄움`(mm). 거리는 스스로 계산해 찍는다 |
| `주기` | 도면 오른쪽에 적을 말의 목록 |

건물 하나에 적는 것:

| 칸 | 뜻 |
|---|---|
| `이름`, `구분` | 구분은 `기존` · `신설` · `칸`(평면도의 안쪽 칸). 신설은 ①②, 기존은 가·나 표가 붙는다 |
| `위치`, `가로`, `세로` | 왼쪽 아래 모서리의 `[x, y]`와 크기. 비스듬하면 `회전`(시계 반대 방향, 도) |
| `꼭짓점` | 사각형이 아니면 위 셋 대신 꼭짓점 목록 |
| `용도`, `구조`, `설명` | 오른쪽 개요표에 찍힌다 |
| `대장면적` | 건축물대장의 건축면적. 적으면 개요표에 이 값이 찍히고 그린 넓이와 맞춰 본다 |
| `가로치수`, `세로치수` | 건물 크기 치수를 놓을 쪽. `아래`·`위`·`없음`, `왼쪽`·`오른쪽`·`없음` |
| `문` | 평면도의 문과 창. `벽`(`아래`·`오른쪽`·`위`·`왼쪽`), `띄움`(벽의 왼쪽 또는 아래 끝에서), `폭`, `이름` |

면적은 가로와 세로(또는 꼭짓점)에서 스스로 계산해 찍는다. 신청서에 적는 면적과 같은지 맞춘다.

## 경사 참고도

땅이 얼마나 비탈졌는지 미리 보려고 만드는 한 장이다. 산지전용, 개발행위허가, 초지 조성처럼 경사가 걸리는 일을 시작할 때, 관청이나 전문가와 상담하기 전에 쓴다.

```bash
slope.py make 37.6586 126.9779                          # 가운데 좌표(위도 경도), 한 변 300m
slope.py make 37.6586 126.9779 --size 500 --address "○○시 ○○동 000" --out 업무/<업무 이름>/첨부
```

- **위도와 경도**는 `parcel.py show`가 알려 주는 필지의 가운데 좌표를 쓴다. 브이월드 인증키가 없으면 신청인에게 지도 앱에서 그 땅을 길게 눌러 나오는 좌표를 불러 달라고 한다.
- 도면에는 경사 구간별 색(5도 단위), 등고선, 구간별 면적 비율, 평균 경사, 25도 이상 면적, 표고 범위가 찍힌다. 같은 숫자가 화면에도 나온다.
- 인증키가 필요 없는 공개 표고 자료(Mapzen Terrain Tiles, 원자료 SRTM 등)를 쓴다. 조회할 때 그 땅이 들어 있는 지도 타일 번호(몇 킬로미터 단위)만 밖으로 나간다.
- **참고용이다.** 표고 격자가 약 30m라서 건물 한 채나 작은 필지의 경사는 나타나지 않는다. 나무와 건물의 높이가 섞여 있어 숲과 시가지는 실제보다 급하게 나올 수 있다. 범위는 200m 이상으로만 그린다.
- **평균경사도 조사서를 대신하지 못한다.** 산지전용허가기준은 전용하려는 산지의 평균경사도가 25도 이하이고, 100제곱미터씩 나눠 잰 경사도가 25도 이상인 면적이 100분의 40 이하일 것을 요구한다(「산지관리법 시행령」 별표 4, 확인일 2026-11-16). 100제곱미터 단위는 이 자료로 잴 수 없다. 조사서는 누가 어떻게 만들어야 하는지 관청에 묻는다 `[관청 확인]` `[전문가 확인]`.
- 이 도면의 숫자를 신청서나 사업계획서에 "평균경사도"로 옮겨 적지 않는다. 적어야 하면 "공개 표고 자료로 본 참고값"이라고 밝힌다.

## 반드시 지킬 것

1. **짐작해서 그리지 않는다.** 자리, 거리, 방위, 경계 가운데 받지 못한 것이 있으면 묻는다. 스크립트도 방위와 위치근거가 없으면 그리지 않는다.
2. **모르는 경계는 그리지 않는다.** 대지경계선을 대충 그려 넣으면 경계까지의 거리가 틀린 도면이 된다. 경계 자료가 없으면 빼고 주기에 "대지경계선은 자료가 없어 표시하지 않음"이라고 적는다. 경계까지의 거리를 요구하는지는 `[관청 확인]`.
3. **이 도면은 신청인이 그린 도면이다.** 측량 성과도나 건축사가 만든 설계도서가 아니다. 도면에도 그렇게 찍힌다. 경계가 다투어지는 땅, 경계에 바짝 붙여 놓는 건물은 경계복원측량이나 건축사에게 맡기라고 말한다 `[전문가 확인]`.
4. **이 도구로 그릴 수 없는 것을 안다.** 건축허가·건축신고에 붙이는 설계도서(「건축법 시행규칙」 별표 2의 배치도는 대지의 종·횡단면도, 건축선, 주차·조경 계획까지 담는다), 3층 이상 가설건축물의 입면도·단면도·구조도(같은 규칙 제13조제8항)는 건축사·구조기술사의 일이다.
5. **서류와 숫자를 맞춘다.** 도면의 건물 이름, 용도, 구조, 가로·세로, 면적, 동 수가 신청서와 `00-기초사실.md`에 적힌 것과 같아야 한다. 하나를 고치면 도면을 다시 그린다.
6. **관청이 원하는 꼴을 먼저 묻는다.** 지적도 위에 표시한 도면을 원하는 곳, 정해진 축척을 원하는 곳, 사진을 함께 원하는 곳이 있다 `[관청 확인]`. 지적도 위 표시를 원하면 지적도 등본에 건물 자리를 옮겨 그리는 법을 신청인에게 안내한다.
7. **개인정보.** 도면에는 주소와 건물만 넣는다. 작성자 이름 말고는 사람 정보를 넣지 않는다. 도면은 신청인의 컴퓨터에서 만들어지고 밖으로 보내지 않는다.
