# 도면 그리기

관청은 신청서에 **배치도**(땅 위에 건물이 어디에 놓이는지)와 **평면도**(건물 하나를 위에서 본 모양과 크기)를 붙이라고 한다. 가설건축물 축조신고는 「건축법 시행규칙」 제13조제1항제1호가 "가설건축물의 배치도 및 평면도"를 붙이라고 정한다(확인일 2026-11-16). 간단한 건물은 신청인이 직접 그려도 받는 곳이 많다 `[관청 확인]`.

이 스킬은 신청인이 불러 준 치수를 받아 적어 도면으로 옮긴다. **측량을 대신하지 않는다.**

## 그리기 전에 받을 것

자리와 치수를 짐작해서 그리면 틀린다. 아래를 신청인에게서 받은 뒤에 그린다. 모르는 것이 있으면 그리지 않고 묻는다.

| 받을 것 | 어디서 |
|---|---|
| 새로 놓을 건물의 가로, 세로, 구조, 용도 | 신청인. 컨테이너는 실물이나 견적서의 규격 |
| 기존 건물의 가로, 세로 | 건축물대장의 면적만으로는 모양을 알 수 없다. 신청인이 재거나 기존 도면에서 읽는다. 대장 기록은 `building-lookup` 스킬로 맞춘다 |
| **새 건물이 놓일 자리** — 기존 건물이나 경계에서 어느 쪽으로 몇 미터 | 신청인이 현장에서 잰다. 차가 드나드는 길, 문 앞, 비탈처럼 놓을 수 없는 곳도 함께 묻는다 |
| **방위** — 도면에서 북쪽이 어느 쪽인지 | 지적도, 지도 앱, 나침반 |
| 대지경계선의 모양과 길이, 대지면적 | 지적도 등본, 토지대장. 경계를 모르면 그리지 않고 주기에 적는다 |
| 대지에 닿은 도로나 진입로의 위치와 너비 | 지적도, 현장 |
| 문과 창의 위치와 폭 (평면도) | 신청인, 실물 |

받은 값은 `00-기초사실.md`에 출처와 함께 적는다. 신청인에게 손으로 그린 약도나 지적도 사진을 받으면 가장 빠르다.

## 그리는 법

이 스킬 폴더의 `scripts/draw.py`를 쓴다. 파이썬 3만 있으면 SVG가 나오고, 크롬이나 엣지가 있으면 PDF와 미리보기 PNG도 나온다.

```bash
draw.py example 배치도 > 업무/<업무 이름>/첨부/배치도.json    # 보기 파일로 시작
draw.py example 평면도 > 업무/<업무 이름>/첨부/평면도.json
draw.py check 배치도.json                                  # 적힌 값 점검
draw.py make 배치도.json                                   # 같은 폴더에 .svg .pdf .png
```

1. 보기 파일을 만들고 신청인의 값으로 바꿔 적는다.
2. `make`로 그린다. 고쳐야 할 것이 있으면 그리지 않고 알려 준다. `[살필 것]`으로 나오는 것은 그려지지만 하나씩 확인한다.
3. **PNG를 열어 눈으로 본다.** 건물이 말한 자리에 있는지, 방위표가 맞는지, 글자와 치수가 겹치지 않는지. 겹치면 `가로치수`·`세로치수`의 자리를 바꾸거나 치수의 `띄움`을 준다.
4. 신청인에게 PNG를 보여 주고 **"이 자리가 맞습니까"**를 확인받는다. 확인받기 전에는 내지 않는다.
5. 낼 때는 PDF를 붙인다. A4 가로 한 장이다.

## 적는 칸

길이와 좌표는 모두 **미터**다. x는 도면의 오른쪽으로, y는 도면의 위쪽으로 커진다. 원점은 편한 곳(보통 대지의 왼쪽 아래 모서리나 기존 건물의 모서리)에 둔다. 도면의 치수 글자는 mm로 찍힌다.

| 칸 | 뜻 |
|---|---|
| `종류` | `배치도` · `평면도` · `현황도` (현황도는 지금 있는 그대로를 그린 배치도) |
| `제목`, `주소`, `용도` | 도면 이름, 대지 주소, 어디에 내는 도면인지 |
| `작성일`, `작성자` | 도면 아래에 찍힌다. 작성자는 비워도 된다 |
| `방위` | 도면에서 북쪽이 가리키는 쪽. `위` · `오른쪽` · `아래` · `왼쪽`, 또는 위에서 시계 방향으로 잰 각도. **필수** |
| `위치근거` | 자리와 거리를 어디서 얻었는지. 배치도와 현황도는 **필수**이고 도면의 주기에 찍힌다 |
| `축척` | 비우면 종이에 맞는 표준 축척을 고른다. 정하려면 숫자(300이면 1/300) |
| `대지경계` | 경계선의 꼭짓점 `[x, y]` 목록. `대지면적`은 제곱미터 |
| `건물` | 아래 표 |
| `표시` | `도로`·`구역`(위치·가로·세로 또는 꼭짓점, `이름`), `글자`(`위치`, `글`), `화살표`(`시작`, `끝`, `글`) |
| `치수` | 두 점 사이 거리. `시작`, `끝`, 필요하면 `띄움`(mm). 거리는 스스로 계산해 찍는다 |
| `주기` | 도면 오른쪽에 적을 말의 목록 |

건물 하나에 적는 것:

| 칸 | 뜻 |
|---|---|
| `이름`, `구분` | 구분은 `기존` · `신설` · `칸`(평면도의 안쪽 칸). 신설은 ①②, 기존은 가·나 표가 붙는다 |
| `위치`, `가로`, `세로` | 왼쪽 아래 모서리의 `[x, y]`와 크기. 비스듬하면 `회전`(시계 반대 방향, 도) |
| `꼭짓점` | 사각형이 아니면 위 셋 대신 꼭짓점 목록 |
| `용도`, `구조`, `설명` | 오른쪽 개요표에 찍힌다 |
| `가로치수`, `세로치수` | 건물 크기 치수를 놓을 쪽. `아래`·`위`·`없음`, `왼쪽`·`오른쪽`·`없음` |
| `문` | 평면도의 문과 창. `벽`(`아래`·`오른쪽`·`위`·`왼쪽`), `띄움`(벽의 왼쪽 또는 아래 끝에서), `폭`, `이름` |

면적은 가로와 세로(또는 꼭짓점)에서 스스로 계산해 찍는다. 신청서에 적는 면적과 같은지 맞춘다.

## 반드시 지킬 것

1. **짐작해서 그리지 않는다.** 자리, 거리, 방위, 경계 가운데 받지 못한 것이 있으면 묻는다. 스크립트도 방위와 위치근거가 없으면 그리지 않는다.
2. **모르는 경계는 그리지 않는다.** 대지경계선을 대충 그려 넣으면 경계까지의 거리가 틀린 도면이 된다. 경계 자료가 없으면 빼고 주기에 "대지경계선은 자료가 없어 표시하지 않음"이라고 적는다. 경계까지의 거리를 요구하는지는 `[관청 확인]`.
3. **이 도면은 신청인이 그린 도면이다.** 측량 성과도나 건축사가 만든 설계도서가 아니다. 도면에도 그렇게 찍힌다. 경계가 다투어지는 땅, 경계에 바짝 붙여 놓는 건물은 경계복원측량이나 건축사에게 맡기라고 말한다 `[전문가 확인]`.
4. **이 도구로 그릴 수 없는 것을 안다.** 건축허가·건축신고에 붙이는 설계도서(「건축법 시행규칙」 별표 2의 배치도는 대지의 종·횡단면도, 건축선, 주차·조경 계획까지 담는다), 3층 이상 가설건축물의 입면도·단면도·구조도(같은 규칙 제13조제8항)는 건축사·구조기술사의 일이다.
5. **서류와 숫자를 맞춘다.** 도면의 건물 이름, 용도, 구조, 가로·세로, 면적, 동 수가 신청서와 `00-기초사실.md`에 적힌 것과 같아야 한다. 하나를 고치면 도면을 다시 그린다.
6. **관청이 원하는 꼴을 먼저 묻는다.** 지적도 위에 표시한 도면을 원하는 곳, 정해진 축척을 원하는 곳, 사진을 함께 원하는 곳이 있다 `[관청 확인]`. 지적도 위 표시를 원하면 지적도 등본에 건물 자리를 옮겨 그리는 법을 신청인에게 안내한다.
7. **개인정보.** 도면에는 주소와 건물만 넣는다. 작성자 이름 말고는 사람 정보를 넣지 않는다. 도면은 신청인의 컴퓨터에서 만들어지고 밖으로 보내지 않는다.
