# 도장 그림 만들기

신청인의 이름이나 단체 이름으로 도장 그림을 만든다. 만든 그림은 바탕이 투명해서 워드·한글·PDF 문서 위에 바로 얹을 수 있다.

## 만들기 전에 가릴 것

1. **누구의 도장인가.** 신청인 본인, 또는 신청인이 대표자이거나 도장을 쓸 권한을 받은 단체의 도장만 만든다. 남의 이름, 거래 상대방, 관청의 직인은 만들지 않는다. 누구 것인지 분명하지 않으면 묻는다.
2. **어디에 쓸 것인가.** 아래 표로 가른다. 인감도장을 찍어야 하는 서류라면 만들지 않고 실제 도장을 찍으라고 안내한다.

| 쓸 곳 | 이 그림을 써도 되는가 |
|---|---|
| 견적서, 거래명세서, 안내문, 내부 결재 서류, 상대방이 그림 도장을 받아 주는 문서 | 쓴다 |
| 전자로 내는 신청에서 서명·날인 칸에 도장 그림을 받아 주는 경우 | 받는 곳이 그림 도장을 받는지 먼저 확인한다 `[관청 확인]` |
| 등기 신청서, 인감증명서와 함께 내는 서류, 위임장처럼 **등록된 인감을 찍으라고 정한 서류** | 쓰지 않는다. 등록된 인감도장을 종이에 직접 찍는다 |
| 서명 또는 기명날인을 요구하는 서류 | 받는 곳에 따라 다르다 `[관청 확인]`. 확인 전에는 실제 도장을 찍는다 |

이 그림은 등록된 인감과 모양이 다르다. 인감증명서의 인영과 대조하는 서류에 얹으면 보정이나 반려가 나온다. 날인 요건은 그 서류의 근거 조문과 서식 주의사항을 `law-lookup`·`office-doc` 스킬로 읽어 확인하고, 단정하지 않는다.

## 만드는 법

이 스킬 폴더의 `scripts/seal.py`를 쓴다. 파이썬 3만 있으면 SVG가 나오고, 크롬이나 엣지가 있으면 PNG와 견본 모음 그림도 나온다.

```bash
seal.py corp "농업회사법인 한빛농장 주식회사" --out 업무/<업무 이름>/첨부    # 법인·단체 도장 견본 모음
seal.py corp "농업회사법인 한빛농장 주식회사" --pick 4 --out 업무/<업무 이름>/첨부   # 4번 모양으로 만들기
seal.py corp "사단법인 푸른숲" --center 이사장                          # 가운데 글자 바꾸기
seal.py name "홍길동"                                                  # 개인 도장 견본 모음
seal.py name "홍길동" --pick 4                                         # 4번 모양으로 만들기
```

1. 이름은 **등기부나 고유번호증, 주민등록에 적힌 대로** 받는다. 띄어쓰기는 빼고 그린다. 법인 도장 둘레는 24자까지 들어간다.
2. 견본 모음(`…-견본.png`)을 만들어 **직접 열어 본 뒤** 신청인에게 보여 주고 번호를 고르게 한다. 글자가 깨지거나 네모로 나오면 그 컴퓨터에 한글 글꼴이 없는 것이니 `--font`로 글꼴 파일을 준다.
3. 고른 번호로 `--pick`을 주어 만든다. `이름-법인도장.svg`·`.png` 또는 `이름-도장.svg`·`.png`가 나온다. PNG는 바탕이 투명하다.
4. 만든 PNG를 열어 이름의 글자가 하나도 빠지거나 틀리지 않았는지 한 글자씩 본다.
5. 문서에 얹을 때는 서명·날인 칸의 이름 끝 글자에 반쯤 걸치게 놓는다. 크기는 법인 도장 지름 18~24mm, 개인 도장 12~15mm가 흔하다 `[확인 필요: 받는 곳이 정한 크기]`.

## 모양

**법인·단체 도장 (corp)** — 바깥 원 둘레에 단체 이름이 맨 위 표시(점이나 별) 오른쪽부터 시계 방향으로 돈다. 글자 윗부분이 바깥을 향하므로 아래쪽 글자는 뒤집혀 보인다. 안쪽 원에는 직함이 들어간다.

- 둘레 글꼴 2종(명조, 고딕) × 가운데 글자 × 맨 위 표시(점, 별). 가운데 글자는 주지 않으면 `대표이사`와 `代表理事` 두 가지로 만든다.
- 가운데 글자는 `--center`로 바꾼다. 여러 번 주면 그만큼 견본이 늘어난다. 비영리법인은 `이사장`, 조합은 `조합장`, 개인사업자는 `대표`처럼 **정관이나 등기부에 적힌 직함**을 쓴다. 한자 네 글자는 오른쪽 줄부터 세로로 읽게 놓는다.

**개인 도장 (name)** — 타원(첫 글자만, 세로 이름 명조·고딕), 원, 네모(고딕, 명조, 겹테) 7종. 글자 수가 홀수면 끝에 `인`(한자 이름이면 `印`)을 붙여 칸을 채운다.

**가진 글꼴 쓰기** — `--font 글꼴파일`을 주면 그 글꼴로 그린 모양이 견본 맨 앞에 더해진다(.ttf .otf .woff .woff2). 전서체처럼 도장에 쓰는 글꼴을 가지고 있을 때 쓴다. 글꼴 파일은 SVG 안에 들어가므로, 그 글꼴의 사용 조건이 문서에 넣어 쓰는 것을 허락하는지 신청인이 확인한다. 전서체는 이 스킬에 들어 있지 않다.

## 지킬 것

- 이름을 지어내거나 줄여 쓰지 않는다. 신청인이 준 이름과 `00-기초사실.md`의 이름이 다르면 멈추고 묻는다.
- 만든 그림과 이름은 내 컴퓨터에만 남는다. 밖으로 보내지 않는다.
- 도장 그림을 얹은 서류를 낼 때는 `10-제출서류-목록.md`의 날인 칸에 "도장 그림"이라고 적어, 실제 도장을 찍은 서류와 구별한다.
- 진짜 도장처럼 보이게 번짐이나 얼룩을 넣어 달라는 요청은 받지 않는다. 등록된 인감의 인영을 본떠 그리지도 않는다.
