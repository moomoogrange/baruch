# 법령 조회

법령 원문은 [law-go-kr-obsidian](https://github.com/moomoogrange/law-go-kr-obsidian) 저장소에 있다. 국가법령정보센터(law.go.kr)의 법령을 `법령/{법령명}/{법률|시행령|시행규칙|○○부령}.md` 꼴로 옮긴 것이다.

## 처음 한 번

이 스킬 폴더의 `scripts/law.py`를 쓴다. 파이썬 3과 git만 있으면 된다.

```bash
python3 <이 스킬 폴더>/scripts/law.py setup   # 내려받기. 이미 있으면 최신으로 갱신
```

내려받는 곳은 `~/.local/share/baruch/law-go-kr-obsidian`이다. 이미 다른 곳에 받아 둔 사본이 있으면 `BARUCH_LAW_DIR` 환경변수로 그 폴더를 가리킨다.

## 쓰는 법

```bash
law.py where                               # 저장소 위치와 마지막 갱신일
law.py find 성평등가족부 비영리법인          # 법령 이름 찾기 (낱말을 모두 포함하는 것)
law.py meta 법인세법                        # 파일 목록, 공포일, 시행일, law.go.kr 주소
law.py toc 민법                             # 조문 제목 목록
law.py art 민법 32                          # 조문 본문 (기본은 법률)
law.py art 법인세법 39 시행령                # 시행령·시행규칙은 파일 이름을 뒤에 붙인다
law.py art 법인세법 공익법인등의범위 시행규칙  # 번호 대신 조문 제목 낱말로도 찾는다
law.py grep "설립허가" 행정권한의위임및위탁에관한규정   # 본문 검색 (법령명을 빼면 전체 검색)
```

법령 이름은 띄어쓰기 없이 적어도 되고 일부만 적어도 된다. 여러 건이 걸리면 후보를 보여 준다.
저장소 폴더를 Read·Grep 도구로 직접 읽어도 된다. 위키링크 `[[법령/민법/법률|민법]]`은 그 법령 파일의 경로다.

## 반드시 지킬 것

1. **시행일을 함께 적는다.** `art` 결과 첫 줄에 `[법령 제목 · 파일 · 시행 날짜]`가 나온다. 인용할 때 이 날짜를 붙인다.
2. **저장소는 사본이다.** `where`가 알려 주는 마지막 갱신일 뒤의 개정은 들어 있지 않다. 신청인에게 이 날짜를 알리고, 제출 전에 결과 끝에 붙은 law.go.kr 주소에서 현행 조문을 확인하게 한다.
3. **가지번호가 빠져 있다.** 저장소는 제18조의3을 제목에 `제18조`로만 적는다. 그래서 `art 법인세법 18 시행규칙`은 제18조, 제18조의2, 제18조의3을 모두 보여 준다. 조문 **제목**을 보고 맞는 것을 고르고, 서류에 조 번호를 적어야 하면 law.go.kr에서 정확한 번호를 확인한 뒤 적는다. 확인하지 못했으면 「법령명」 "조문 제목"으로 가리킨다.
4. **없는 것은 없다고 한다.** 별지 서식, 고시, 훈령·예규, 지방자치단체 조례, 관청 내부 지침은 이 저장소에 없다. 찾지 못한 조문은 `[조문 미확인]`으로 표시한다.
5. **읽은 만큼만 말한다.** 조문 본문을 읽지 않고 번호나 내용을 말하지 않는다.
