# 설립허가 신청 서류

근거는 해당 부처 규칙의 "설립허가의 신청" 조문이다. **반드시 그 부처 규칙을 직접 읽고** 아래 목록과 다른 점을 고친다. 아래는 여러 부처 규칙에 공통으로 나오는 구성이다.

| 번호 | 서류 | 틀 | 요점 |
|---|---|---|---|
| 1 | 법인 설립허가 신청서 | 부처 규칙의 별지 서식 (law.go.kr 또는 관청 누리집에서 받음) | 신청인은 설립발기인 대표. 서식 칸은 `templates/설립허가-신청서-메모.md`로 미리 채워 둔다 |
| 2 | 설립발기인 인적사항 | `templates/발기인-인적사항.md` | 성명, 생년월일, 주소, 약력. 발기인이 법인이면 명칭·주사무소·대표자·정관 |
| 3 | 정관 | `templates/정관-사단법인.md` | 민법 제40조 기재사항 7가지. 발기인 전원 기명날인 |
| 4 | 재산목록과 증명서류 | `templates/재산목록.md` | 증명서류(잔액증명서, 등기사항증명서 등). 내놓기로 한 재산은 출연 확인 서류 |
| 5 | 사업계획서와 수입·지출 예산서 | `templates/사업계획서-예산서.md` | 해당 사업연도분. 정관의 사업 조항과 항목이 맞아야 한다 |
| 6 | 임원 취임 예정자 인적사항과 취임승낙서 | `templates/임원-취임승낙서.md` | 성명, 생년월일, 주소, 약력. 임원마다 승낙서 1부 |
| 7 | 창립총회 회의록 | `templates/창립총회-회의록.md` | 정관 채택, 임원 선출, 사업계획·예산 승인, 재산 출연을 의결한 기록 |

신청서의 법인 소재지는 정관의 사무소 소재지와 같아야 한다. 관청이 주로 보는 다섯 가지(업무 범위, 설립의 필요성, 실현 가능성, 명칭, 재정적 기초)는 `생활법령-요점.md`에 있다. 서류를 쓸 때 이 다섯 가지에 답이 되게 쓴다.

관청이 더 달라고 할 수 있는 것: 발기인·임원의 인감증명서, 사무실 임대차계약서 또는 사용승낙서, 회원 명부, 사전 활동 실적 자료. `[관청 확인]`

## 서류별 쓰는 법

**정관**
- 민법 제40조가 요구하는 것: 목적, 명칭, 사무소의 소재지, 자산에 관한 규정, 이사의 임면에 관한 규정, 사원자격의 득실에 관한 규정, (정한 경우) 존립시기나 해산사유. 하나라도 빠지면 안 된다.
- 목적과 사업은 주무관청 소관과 맞아야 한다. 소관이 아닌 사업을 넣으면 보완 요구가 나온다.
- 기부금영수증을 줄 계획이면 `세무와-기부금영수증.md`의 "정관에 넣을 것" 세 가지를 넣는다.
- 주무관청 표준정관이 있으면 그 조문 순서와 문구를 따른다.

**사업계획서·예산서**
- 사업마다 목적, 대상, 내용, 시기, 횟수, 예상 인원, 드는 돈을 적는다. 할 수 있는 만큼만 적는다. 허가 기준이 "실현 가능할 것"이다.
- 수입은 출처별로(회비, 후원금, 참가비, 기타), 지출은 사업비와 운영비로 나눈다. 수입 합계와 지출 합계가 맞아야 한다.
- 참가비처럼 대가를 받는 사업은 수익사업일 수 있다. 예산서에 따로 적는다. 수익사업을 하려면 정관에 근거 조항과 구체적인 사업 종목이 있어야 한다.
- 사단법인은 회원 수, 연회비 액수, 회비를 걷는 방법이 재정적 기초의 근거가 된다. 회비 수입의 산출 근거를 분명히 적는다.

**창립총회 회의록**
- 실제로 연 회의를 그대로 적는다. 일시, 장소, 참석자, 안건, 발언 요지, 의결 결과(찬성·반대·기권 수).
- 안건: ① 임시의장 선출 ② 설립 취지 채택 ③ 정관 심의·채택 ④ 임원 선출 ⑤ 재산 출연 ⑥ 사업계획과 예산 승인 ⑦ 사무소 설치 ⑧ 설립허가 신청을 대표에게 맡김.
- 끝에 의장과 참석 발기인(또는 총회에서 뽑은 서명인)이 기명날인한다. 관청이 간인(쪽 사이 도장)을 요구하는지 확인한다. `[관청 확인]`

## 서류 사이 대조표

다 쓴 뒤 아래를 하나씩 맞춰 보고 `법인설립/99-점검표.md`에 결과를 적는다. 어긋나면 고친다.

| 맞춰 볼 것 | 나오는 서류 |
|---|---|
| 법인 명칭 (글자, 띄어쓰기, "사단법인" 붙이는 위치) | 신청서, 정관, 회의록, 사업계획서, 재산목록, 취임승낙서 |
| 주사무소 주소 | 신청서, 정관, 회의록, (임대차계약서) |
| 명칭이 기존 법인과 같지 않은가 (인터넷등기소 상호 검색 결과) | 기초사실, 신청서 |
| 정관 부칙에 설립 당시 임원이 적혀 있는가 | 정관, 회의록 |
| 목적, 사업 항목 | 정관, 사업계획서, 신청서 |
| 발기인 명단 (이름, 수) | 인적사항, 정관 날인, 회의록 참석자 |
| 임원 명단, 직위, 임기 | 정관(임원 수·임기), 회의록(선출 결과), 인적사항, 취임승낙서 |
| 임원 수가 정관의 정수 안에 있는가 | 정관, 회의록 |
| 재산 총액, 항목별 금액 | 재산목록, 증명서류, 회의록(출연 의결), 예산서 |
| 예산 수입 합계 = 지출 합계 | 예산서 |
| 사업연도 | 정관, 사업계획서, 예산서 |
| 창립총회 날짜 ≤ 정관 작성일·승낙서 날짜 ≤ 신청일 | 회의록, 정관, 취임승낙서, 신청서 |
| 민법 제40조 기재사항 7가지 | 정관 |
| 공익법인 지정용 조항 3가지 (기부금영수증이 필요할 때) | 정관 |
