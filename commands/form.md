`office-doc` 스킬의 "관청 서식" 부분을 따른다. 요청: $ARGUMENTS

1. 요청이 "목록"으로 시작하면 `forms.py list "법령 이름" [낱말]`로 서식 이름과 번호를 보여 주고 끝낸다.
2. 요청을 비웠으면 지금 업무의 카드와 `references/서식-목록.md`에서 이 업무에 쓰는 서식을 찾는다. 카드에 번호가 없으면 `forms.py list`로 찾아 신청인에게 어느 서식인지 확인받는다. 짐작으로 고르지 않는다.
3. `forms.py get "법령 이름" 번호 -o 업무/<업무>/서식`으로 받는다. 받은 서식의 시행일과 받은 날을 `00-기초사실.md`나 서류 목록에 적는다. 이미 받아 둔 파일은 신청인이 적던 것일 수 있으니 다시 받기 전에 묻는다.
4. 서식의 칸을 읽어(`ieumoffice hwp read`, 없으면 `law.py live annex`) **칸마다 적을 내용**을 `업무/<업무>/서식/<서식 이름>-적을-내용.md`로 정리한다. 모르는 칸은 `[확인 필요]`로 남긴다. 주민등록번호는 적지 않는다.
5. 이음오피스가 있고 신청인이 열어 달라고 하면 `ieumoffice open`으로 서식을 연다. 신청인이 정리된 내용을 보고 직접 옮겨 적는다. 바룩이 서식 파일에 직접 써 넣는 것은 신청인이 해 달라고 할 때만 한다.
6. 법원·등기소 양식, 고시·훈령의 서식, 조례의 서식은 여기서 받지 못한다. 어디서 받는지 알려 준다.
